# 公开原文与免费数据路径

## 使用顺序

先接口，后原文，最后研究检索。结构化接口能一次取到五年序列与当期数据时，不必逐份下载年报；原文只在**接口无字段、数值冲突、口径变更、需附注语境、用户要求**时定向打开，且只读该字段所需页。免费行情源（Yahoo Finance、Stooq 等）与付费连接器同属接口层，按同一标准核验代码、交易日、复权方式与延迟。

## 降级链（连接器取不到关键数据时）

首选连接器不可用或缺少所需字段时，**不得停止取数或填 0**，按此顺序降级，并逐项留痕：

1. 同环境其它已连接接口 → 2. **免费公开接口**（见下表）→ 3. 法定披露原文定向取字段 → 4. 具名权威公开统计。

**免费源的实际能力边界**（不要假设它什么都有）：

| 免费源 | 通常能补 | 通常补不了 |
|---|---|---|
| Yahoo Finance chart / quoteSummary | 收盘价、成交量、市值、PE/PB/PS、部分总收入/净利、跨市场报价 | A 股分部拆分、扣非净利、合同负债、研发资本化、股东明细；字段常滞后或口径随供应商变 |
| Stooq | 历史日线价格、部分指数 | 财务科目几乎不覆盖 |
| 交易所公开行情页（SSE/SZSE/HKEX） | 官方收盘价、成交额、股本、停复牌 | 结构化财务报表与估值倍数 |
| 巨潮/披露易/EDGAR | 全部法定原文与公告 | 需要解析 PDF/HTML，非结构化 |

免费源多为二手整理（证据层级 C），可支撑数据陈述，**不能单独支撑因果解释**；关键结论仍须回到法定原文。A 股与港股标的常出现「免费源只有总量财务、没有分部与附注」的情况，此时对应字段按 `not_disclosed` 或 `unavailable` 标注已查范围，不用其它指标顶替。

## 检索和访问纪律

一次正常请求同时检验可达性与内容，不先为每个域名额外发一次探测。HTTP200可能是首页、验证码或空数据，不代表取得财报；重定向跟到真实原文，记录最终URL。限流尊重访问规则、降频或换独立合法来源，不绕过登录、付费、验证码或用户拒绝。遇到工具/安全拒绝，不经其它工具重试等价受限请求。

公司IR可作原文镜像或导航，但发布稿与法定披露冲突时以最新有效法定原文为准。报告PDF必须按宿主PDF读取规范处理；无法打开的原文标“本次未能取得”。网页摘要不进入“已打开原文”清单。

接口主取数时，检索成本主要落在三处：锚定核对那一份原文的关键页、接口缺口字段的对应附注、以及最近披露日之后的重大公告。不必为已由接口覆盖的科目再走一遍全文检索。

同行财报通常可取，但准确分部、研发人数/资本化、CCASS受益人、近90天评级修正、一致预期时间序列可能不公开。预先列缺口并按状态表示，不用搜索到的单家研报替代共识。

自建历史估值必须有当时已披露财务、有效股本、原始价格与公司行动：PIT可见性优先，不用今天TTM回填五年；无PIT输入就说明“无法可靠重建”，不强画估值曲线。
