# 报告结构、解释和验收

## 输出与首屏

默认单文件UTF-8离线HTML：`{代码}_{公司简称}_基本面深度拆解_YYYYMMDD.html`，用户另指定格式则遵从。不发布网站、不建Page/Canvas、不自行转PDF。聊天仅3–6句：完成状态、主业、财务、估值、关键缺口；附件提供完整内容，不在聊天复制长表。

首屏写公司代码/身份、分析日和时区、各地已完成收盘交易日、原币和RMB、FX日期与类型、目标财年、最新年度与最新中期。**加一行取证方式声明**：`api_first` 还是 `document_first`；接口取得哪些字段、哪些字段读了原文、锚定核对了几个字段、有无差异。逐行列五个年度期次与当年已披露中期：期间、披露日、来源链接或工具参数、最新一期标签；接口取数的写字段ID与JSON路径，读过原文的另加页码。“本次数据源”只列实际取用并经核对的来源、连接器与字段；安装清单另作运行记录。因此未覆盖的附注类信息（审计意见、关联交易、客户集中度等）单列一行说明。

多地上市首表逐地列代码、币种、收盘价、换算每基础股RMB价格、该类发行股本、该类市场股份价值。不得加总；说明ADR比例和同权核验。先列三条摘要结论，正文末再列证据锚定版总结。

## 每节共同要求

表/图 → 来源与期次 → `class="interpretation"`实用解读。解读按“本次已核对数字与期间 → 与前期/同行差异 → 在证据边界内的判断 → 会推翻判断的下一期观察”写；不能只写教学或把表重复一遍。模块主容器id固定module1..module5，末尾summary/risks/watchlist/sources供质检。

目标公司年度趋势必须保留五年原值，当前财年每个已披露中期分别展示盈利、现金、资产、营运与债务数据和同区间YoY，累计与单季分表；缺分部/人员科目明确该期未披露，不用较早附注填期。同行突出三年与最新期，底稿五年在可取范围保留，用折叠/页内锚点而非删数据。

## 模块一 主营与利润引擎

列最新年报和当年所有中期的分部/产品/地区：收入、占比、YoY、分部毛利率、毛利额及贡献。未披露独立AI等业务就标缺，不用概念标签构造数字；分部利润与毛利不可互代。收入基本盘、增量来源、利润贡献分开判断。列商业模式、收入总/净额法、客户/供应商集中度。

可替代性是全行业可讨论的研究问题，但证据路径依行业选择：组装/渠道可查同标包报价、核心件客供；品牌/软件可看同配置ASP、留存、涨价传导、续费等公开证据，不强套BOM。报价趋同只支持竞争/规格等假说，不能单独证明无定价权，更不能推定串标；BOM、报价含税和产品代际必须同口径。无证据就明确无法验证。

## 模块二 中国与全球TAM/CAGR

按具名机构列报告名、发布日期、统计区间、地域、产品定义、金额/销量、未来3–5年CAGR/年度预测及原币/RMB。已实现与预测分开，旧报告标旧。不同机构不能相加、平均为一个市场。公司增速和行业同比尽量同期同产品，不把年度增速直接等同多年CAGR。独立第三方统计可以用；构造细分分母不得用于份额或渗透率。没有数据允许缺表/缺图但必须解释已查范围。

## 模块三 同行矩阵与份额

矩阵逐个标准代码、上市地、商业模式、同产品业务收入权重、财政期间、直接竞争/参考。纳入国内A股、中国香港、海外与可读招股书的未上市公司，不能强凑数量。**从矩阵中锁定至少 3 家「核心可比组」**，写入证据账本 `peers`；权重不足、模式不同者降为 reference 并说明，不进入中位数计算。第三方市场份额注明金额/出货、地域、期次与排名；只在公司收入与独立TAM严格同口径时另列“隐含份额测算”，不冒充官方。混业公司整体利润率与合同负债结构也受业务结构影响，连变化率也不是结构免疫指标。

## 模块四 七维诊断

> **同行对照是本节硬性要求**：4.1–4.7 每一节都要有「目标公司 vs 核心同行同期数据」表，并在该节解读中引用同行中位数或差值。逐节指标与规则见本节末「同行对照层」。

### 4.1 一致预期

评级近90天家数/升降、目标价低/中/高及相对同市场收盘空间、未来2–3年营收/归母与ForwardPE、有则近1/3月上修下修。窗口不公开不得写90天；单家卖方预测单独标注。过时目标价、少覆盖、分歧宽时降权，不用自身假设补共识。

### 4.2 盈利质量

五年及当年各期营收/净利/归母/扣非或经调节non-GAAP及YoY，主业利润权重；毛利/营业利润/净利率和同比pp；最近四个完整单季三率与QoQ；ROE、可用杜邦/ROIC；利润—资产增速差；OCF/净利、CapEx、FCF。禁止展示边际毛利率。并表/一次性/低基数先核对再归因。

### 4.3 运营效率

存货、预付、应收、应付、合同负债年度及年内各期时点/YoY；DIO/DSO/DPO/CCC与同比；存货和营收YoY同表，剪刀差；适用时预收款存量比/增速比，否则“不适用/不宜计算”。存货结构、库龄、跌价有则列。显著变化按本公司历史或同行范围识别，不设虚构整数阈值。简化现金流桥列已纳入科目、实际OCF、未解释残差；不足以证明资金缺口或因果。重资产补转固、折旧/CapEx/利用率，银行保险换行业法定指标。

### 4.4 债务与流动性

资产负债率、有息债明细与去重、有息债/权益、经营占款、总负债/TTM OCF、流动/速动、可用现金/短债、净债/EBITDA及利息保障。年内每个期末都列；受限现金、融资后股本变化和偿债期限接公告核对。应付增加既可能谈判优势也可能支付拖延，不天然健康。

### 4.5 研发与技术壁垒

3–5年费用化研发/营收、资本化流量/总投入、人数/占比、当年各期已披露金额和YoY。费用率下降先看绝对额及分母，资本化变化先看政策和同行；人数缺失不能补估。金额或专利数本身不充分证明护城河。

### 4.6 分市场估值

每地收盘价/FX/每基础股价格、该类发行股本与股份价值；同权全股本统一按该地价格的E_m参照；PE/PB/PS、扣非/ForwardPE、可用EV/EBITDA、EY、正TTM FCF Yield、H/A等价差。倍数分母和利润权益一致；不输出加总市值，不用少股本市场股份价值除集团利润。PEG默认3年CAGR且独立多口径适用性判定。五年或实际可用历史PE/PB/PS及25/50/75分位线，声明PIT、剔除、样本。财务转弱与高低分位一起读，比较市场称“价格折价”而不是下单建议。

### 4.7 筹码与公告

机构基金/外资/QFII/社保有可靠拆分才列，去重并标持仓期与披露滞后；CCASS不是受益所有人，13F不是全部基金仓位。董监高/一致行动、12月增减持股数/价格/金额/日期、解禁质押控制权与近重大公告；不存在完整公开分类时明确缺口，不用前十大合计替代。

### 同行对照层（贯穿 4.1–4.7，硬性）

**采集**：每家核心同行按 `references/input-schema.md` 的 `peers` 结构，逐期记录下列指标，每个值带来源ID、报告期、币种/单位与定位。同行财年非自然年制先拆成自然年季度，或用 TTM 对齐；跨市场按分析日同一汇率折 RMB；会计准则差异（CAS/IFRS/GAAP）在表注说明。同行不必逐家通读原文：接口批量取同期关键科目即可，但至少对 1 家做字段级原文核对，其余在表注标明「接口值，未逐项核对」。

| 章节 | 同行必须提供的同期对应指标 |
|---|---|
| 4.1 | 覆盖机构数、评级结构、目标价隐含空间、一致预期营收/归母增速、Forward PE；无共识数据标状态 |
| 4.2 | 营收/归母YoY、毛利率、营业利润率、净利率、ROE、净现比、FCF/营收；至少近 3 年 + 最新可比中期 |
| 4.3 | DIO/DSO/DPO/CCC、存货YoY、营收YoY、剪刀差、合同负债/存货存量比；模式不同时标不可比 |
| 4.4 | 资产负债率、有息负债/权益、流动比率、速动比率、现金/短债 |
| 4.5 | 研发费用率、研发资本化率、研发人员占比（有则列） |
| 4.6 | 各市场 PE-TTM、PB、PS-TTM、Forward PE、盈利收益率、EV/EBITDA（有则列）；统一币种与分母口径 |
| 4.7 | 机构持股比例、近 12 月内部人净增减持；统计口径与时点必须注明，不可比时标不适用 |

**表格结构（每节至少一张）**：`指标 | 目标公司（期间/来源） | 同行A | 同行B | 同行C | 同行中位数 | 目标公司位置（分位/差值） | 口径与来源注`。同行值缺失显示「暂无公开数据 + 已查范围」，中位数只用有效值并注明样本数；少于 3 个有效值不给「中位数结论」，改列逐个对比。

**计算**：`scripts/calc_metrics.py` 从 `peer_comparison_specs` 输出目标值、有效同行样本、中位数、均值、目标−中位数差（pp 或倍）、目标在同行样本中的经验分位，且每个输出带 `source_ids` 与公式。分位只描述位置，不自动等于「优于同行」。

**解读（每节必写）**：明确写出「目标公司 X 为 A%，核心同行中位数 B%，差 A−B = ±C pp，处于样本第 D 分位（N=家）」；再说明这个差异更可能来自产品结构、商业模式、财年口径还是经营效率；最后写下一期哪一组数字会缩小或反转该差异。混业集团整体毛利率、合同负债比、净现比在不同业务权重下不可直接横比绝对值，必须改比同口径变化并写明不可比原因；不得用同行平均值替代对结构差异的核查。

## 模块五 利率锚

同日可比3M/10Y美债、中国10Y观测日与收益率类型，期限差bps；正利差只能叫非倒挂，陡峭化必须历史变化。各地EY与同币种中国国债主对照，美债作为敞口背景；称“盈利收益率—国债利差”，不称真正ERP或无风险股票安全垫。负FCF保留风险但不算Yield。

## 总结、风险和看板

summary三条结论各带支撑数字、期次、章节链接；财务总结同时反映年内节奏、最新锚**与同行位置**，多地估值同权才给价格相对折价。risks三条风险各带可观测指标、历史/同行阈值依据、触发后需要复核的假说，不把毛利静态损失直接当税后净利损失；静态敏感性与预测分开。watchlist列最新值、当前年各期基期、历史/同行阈值依据、下一次披露观察、维持/推翻条件。证据不足可写观测规则，但“连续两期/五年均值”也应注明分析设定和季节性。

## 图表、离线与人工质检

有数据才画：分部占比/毛利贡献、五年营收/归母/三率、利润—资产增速、OCF/净利/净现比、周转、**4.2 / 4.3 / 4.6 各至少一张同行关键指标对比图**、PE/PB/PS历史、EY/国债、近四单季三率、存货/营收/预付同比。柱图/小多图优先密集饼图；单位跨量级时分面。数值图与表从同一数据对象生成，不手输第二份。空值保留缺口断线，不连线伪装数据。

使用内联SVG、base64图片或真正内嵌脚本，禁止CDN、外部字体、本地旁文件依赖、运行时fetch；外部来源导航链接可保留且不影响离线内容。CSS内嵌、手机表格横滚、打印白底。上涨红/下跌绿；库存增加不自动红色“改善”，未知优劣用中性色。HTML template只作排版，不是完成报告。

执行audit_evidence.py检查证据账本、**同行池与 4.1–4.7 对照覆盖**、`api_first` 的锚定核对记录及HTML；有JS再执行语法检查；离线无JS则不必假做node测试。人工检查五模块/七维/总结/风险3条/看板完整、**核心同行不少于3家、每节同行对照表与中位数、每节解读确实引用同行数字、同行可比性与财年/币种对齐**、锚定核对那几组字段确与原表一致、接口缺口项确已读对应原文、当年清单完整、数值与图一致、无不当归因。自动PASS不是投资结论的真实性证明。
