# 运行时连接器适配

## 1. 清点而不假设

使用当前环境提供的清点与发现能力，先读真实schema，再执行。记录连接器标识、显示名、连接状态、enabled、是否能读取工具清单、检查时点。只将已连接、已启用、工具清单可读且实际调用成功者纳入使用来源。已绑定不等于可用。没有清点能力时如实写“本环境无法列出安装清单”，使用可验证的现有能力或公开原文，不伪造清单。

清点记录可含未使用项，但报告“本次实际采用来源”只列真的使用过的来源，避免把安装清单冒充引用。

## 2. 逐字段映射

读取实际工具完整名称、描述、参数、周期枚举、必填字段、权限与市场覆盖。用描述而非名字认定能力；券商个人账户工具不等于上市公司基本面数据。未知schema禁止拼接命名空间或凭历史参数调用。金融供应商如富途、Wind、AliceWind仅为示例。

保存映射：字段 → 实际工具 → 参数 → 返回路径/字段含义 → 返回期次/观测日 → 单位币种 → 原文核验。只发现本次需要的工具，不读取交易下单工具、个人账户或所有插件秘密。

财报首次抽取打印/读取字段ID→展示名→单位映射，按含义验证；同一工具不同市场、板块、报表的ID可以不同。不能默认field 15永远是研发。资产负债表是时点余额，无所谓“单季余额相减”；只有损益、现金流流量做累计还原。

## 3. 状态处理

|状态|动作|
|---|---|
|connected+enabled+tools_read|尝试所需只读工具，并检查实际返回|
|disabled|不调用，按当前环境请求启用；不强迫用户|
|待授权/过期/need_auth|按照宿主规定的授权流程，精确声明所需连接器，成功后重试原请求|
|用户拒绝/跳过|本轮不重复请求，不绕过其拒绝调用等价受限能力|
|无字段/合法返回no data|记录市场与期次覆盖缺口，换公开来源|
|限流/超时/业务错误|诊断，不无限重试；记录原因，按宿主路由降级|

不得虚构连接器标识、授权链接或API密钥。已知授权失败先走宿主连接流程，不能先换网络绕过。不存在可用连接器不影响独立公开财报检索；公开披露与第三方账户授权是不同来源。

## 4. 两条取数路径

- 法定披露路径：先核实报告清单，获取并阅读原文 → 原值与附注 → 连接器对照/派生序列。
- 其它字段路径：已连接且提供字段的金融工具 → 当前环境规定的研究检索 → 权威公开网站/可核对免费源 → 明示状态与缺口。

遵守宿主工具的发现、检索和授权规则；本文件不声明固定命名空间。清点与原文导航可以并行，进入计算前两条路径均完成，避免“先原文”与“先清点”的文字冲突。

## 5. 可迁移的实测教训，不能写成永久参数

此前适配中出现：利润表“全单季”参数返回全季度，但资产负债表相同参数只给Q1与年报，改为累计报告期枚举才返回中报和三季报；研发和财务费用字段ID在不同板块互换；营收拆分混入其它报告期；新闻工具实际名称与路由简写不一致。

将这些现象作为验收项目，而不是给所有连接器写固定financial_type。每次读schema并检查真实返回期次，确认目标财年各期均存在；数据商返回标题不能覆盖行内真实期间。无原文核验的旧实测数字不在新版方法中保留为当前事实。
