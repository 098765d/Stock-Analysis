# 运行时连接器适配

## 1. 清点而不假设

使用当前环境提供的清点与发现能力，先读真实schema，再执行。记录连接器标识、显示名、连接状态、enabled、是否能读取工具清单、检查时点。只将已连接、已启用、工具清单可读且实际调用成功者纳入使用来源。已绑定不等于可用。没有清点能力时如实写“本环境无法列出安装清单”，使用可验证的现有能力或公开原文，不伪造清单。

清点记录可含未使用项，但报告“本次实际采用来源”只列真的使用过的来源，避免把安装清单冒充引用。

## 2. 逐字段映射

读取实际工具完整名称、描述、参数、周期枚举、必填字段、权限与市场覆盖。用描述而非名字认定能力；券商个人账户工具不等于上市公司基本面数据。未知schema禁止拼接命名空间或凭历史参数调用。金融供应商如富途、Wind、AliceWind仅为示例。

保存映射：字段 → 实际工具 → 参数 → 返回路径/字段含义 → 返回期次/观测日 → 单位币种 → 原文核验结果。只发现本次需要的工具，不读取交易下单工具、个人账户或所有插件秘密。

财报首次抽取打印/读取字段ID→展示名→单位映射，按含义验证；同一工具不同市场、板块、报表的ID可以不同。不能默认field 15永远是研发。资产负债表是时点余额，无所谓“单季余额相减”；只有损益、现金流流量做累计还原。

映射完成后立刻做字段级抽样核对：取最近一期接口值与对应法定报告原表值，逐项比营收、成本、营业利润、归母净利、经营现金流、总资产、存货、应收、应付、合同负债。差异来自单位（元/千元/百万）、币种、合并vs母公司、累计vs单季、重述口径的，先归因再采用；不能归因的记为冲突并改用原文值。

## 3. 状态处理

|状态|动作|
|---|---|
|connected+enabled+tools_read|尝试所需只读工具，并检查实际返回|
|disabled|不调用，按当前环境请求启用；不强迫用户|
|待授权/过期/need_auth|按照宿主规定的授权流程，精确声明所需连接器，成功后重试原请求|
|用户拒绝/跳过|本轮不重复请求，不绕过其拒绝调用等价受限能力；**但可改用免费公开接口**，两者不是同一权限|
|无字段/合法返回no data|记录市场与期次覆盖缺口，进入 §3.1 降级链|
|限流/超时/业务错误|诊断，不无限重试；记录原因，按 §3.1 降级|

不得虚构连接器标识、授权链接或API密钥。已知授权失败先走宿主连接流程，不能先换网络绕过。不存在可用连接器不影响独立公开财报检索；公开披露与第三方账户授权是不同来源。

### 3.1 关键数据拿不到时的降级链（强制顺序）

连接器取不到关键财务或行情数据时，**必须继续走完这条链，不得中断交付、不得填 0、不得用旧值兜底**：

|顺序|降级目标|适用与边界|
|---|---|---|
|1|同环境其它已连接的结构化接口|换供应商先看字段口径是否可比，不能直接拼接不同厂商的同一指标|
|2|**免费公开接口**：Yahoo Finance（chart / quoteSummary）、Stooq、交易所公开行情页|补行情、市值、PE/PB、部分总量财务与历史价格；A 股通常缺分部、扣非、合同负债、合同明细，需往下继续|
|3|法定披露原文定向取字段|补免费源缺的科目与附注；只读该字段所在报表页，不整份重读|
|4|具名权威公开统计|行业规模、份额、利率、汇率；写机构、报告名、统计期与定义|

**降级必须留痕**：来源表逐项写「原计划连接器 → 实际来源 → 降级原因」。降级原因按枚举写清：无该市场覆盖、无该字段、权限未授权、用户拒绝、限流超时、字段口径不可比。报告首屏的取证方式声明里要给一句降级概况（例如「连接器未授权，五年财务改用公开接口 + 原文定点核对」）。

**降级不降标准**：免费源数据同样要通过锚定核对（§2 字段级抽样）与币种/期间/复权校验；免费源通常为二手整理（证据层级 C），只能支撑数据陈述，不能单独支撑因果解释；关键结论仍须回到法定原文。免费源的价格必须核验代码后缀、交易日、复权方式与延迟，不能凭接口名断言覆盖 A 股或港股。

## 4. 三条取数路径与优先级

优先级从高到低，命中即停，不重复劳动：

1. **结构化接口（首选）**。已连接且 schema 可读的行情/财务/估值/一致预期/宏观工具。一次调用批量取五年年度 + 当年各期 + 同行同期，比逐份下载原文快一个数量级，且天然带期间标签，减少手工串期风险。免费源（Yahoo Finance、Stooq、交易所公开行情页等）同样属于这一层，只需核验代码、交易日、复权与延迟。**首选连接器不可用时按 §3.1 降级链降到免费接口，而不是放弃取数。**
2. **公开原文定向补取**。仅在接口无字段、数值冲突、口径变更、需附注语境或用户要求时，打开对应法定报告的目标页。只读该字段所在报表与附注，不必整份重读。入口见 fallback-sources.md。
3. **研究检索与二手整理**。用于行业规模、份额、政策、评级与新闻事件；写清机构、报告名、发布期与统计口径，摘要只作导航。

**接口优先的硬性配套——锚定核对。** 接口值要作主证据，必须至少把最新年报与最新一期的核心科目与原表原值逐项比对一次，记录比对字段数、差异项与取舍。没做这一步的接口数据只能当交叉验证，不能单独支撑结论；也不能用「接口已返回」替代「数字已核实」。

同行不必逐家读全文：接口批量取同行同期关键科目即可，但至少对 1 家同行做字段级核对，并在来源表标明其余为接口值、核对情况如何。行业与份额类数据接口通常不覆盖，按第 3 层处理。

遵守宿主工具的发现、检索和授权规则；本文件不声明固定命名空间。清点与取数可以并行，进入计算前须已完成一次锚定核对。

## 5. 可迁移的实测教训，不能写成永久参数

此前适配中出现：利润表“全单季”参数返回全季度，但资产负债表相同参数只给Q1与年报，改为累计报告期枚举才返回中报和三季报；研发和财务费用字段ID在不同板块互换；营收拆分混入其它报告期；新闻工具实际名称与路由简写不一致。

将这些现象作为验收项目，而不是给所有连接器写固定financial_type。每次读schema并检查真实返回期次，确认目标财年各期均存在；数据商返回标题不能覆盖行内真实期间。未经锚定核对的旧实测数字不在新版方法中保留为当前事实。

另有一条常见失真：接口「Gross Profit」或「毛利」字段可能已扣除部分费用或按另一口径计算，与「营业收入−营业成本」不一致。毛利率优先用后者重算，并把接口值仅作对照。
