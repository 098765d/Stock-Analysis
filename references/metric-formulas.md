# 指标口径与解释边界

## 1. 周期、币种和基数

财务流量保留起止日期与annual/ytd/quarter类型，余额取期末。YoY须同区间，余额YoY比上年同日；环比单季比前单季，较期初比上年末。还原Q2=H1−Q1，Q3=9M−H1，Q4=FY−9M，仅减流量，不减余额。缺前一期不可跨缺期还原。TTM=最新FY+本期YTD−去年同区间YTD，或四个连续完整单季；不能累计叠加。五年首年YoY还需要第六年基数，首年周转需前一年末余额；无比较基数保留“不宜计算”。

负/零利润基数不展示普通增长百分比，列“扭亏/转亏/亏损收窄/扩大”及绝对变化；负OCF同理。CAGR仅正起终点且中间未跨亏损时解释，三年CAGR是相隔三年而非三项数据；合并范围、会计政策、处置和一次性事项先核验。并购增长与内生增长不能无拆分就分配；TTM也不会自动同口径。

金额保留原币并统一RMB，股价/市值按具名观测日汇率；跨公司损益可另提供期内平均汇率以隔离汇兑影响，不能混淆即期换算展示与固定汇率内生增速。原币同比作为主趋势，不用各期不同汇率计算无说明的增长。

## 2. 盈利与资产回报

毛利率=(营收−营业成本)/营收；营业利润率=营业利润/营收；净利率=合并净利润/营收，另列归母净利率。分部毛利率缺失不从集团毛利率外推。利润率变化用百分点pp，1pp=100bps；不要用百分比涨幅混淆。

最近四个完整单季同时列毛利率、营业利润率、净利率及QoQ(pp)与同期YoY(pp)。年内各期YTD也保留。取消边际毛利率计算与展示，以单季方向、同区间利润率变化、收入与利润绝对额判断增收是否增利。毛利改善不能自动说明定价权，需拆产品组合、利用率、良率、成本与披露的量价证据。

净利YoY−资产YoY只称“利润—资产增速差”，是扩张效率预警，不是边际ROIC，不能据此独断新增资产低效或规模效应；资产投产滞后、并购和非经常损益可改变方向。ROIC=NOPAT/平均投入资本，明确税率、经营利润、现金剔除、租赁及商誉口径；缺少可靠税率/资本构成不补假设。

杜邦ROE=同口径净利率×资产周转率×权益乘数，要求同一净利、平均资产及平均权益。与公告加权ROE可能不同。PB=PE×(TTM归母利润/期末归母净资产)是同分母恒等式；不能把该比率直接称公告加权ROE，不能用自造恒等式作独立数据验证。

扣非是中国披露口径，non-GAAP不天然等同扣非，需调节表、税后/少数股东与持续经营范围。营业利润不直接当EBIT；财务费用包括汇兑和利息收入，不能全部作为融资利息。

## 3. 现金流质量

净现比=合并OCF/合并净利润；归母版本可并列但注明范围不完全匹配。净利润≤0时不解释普通净现比优劣，列OCF与利润绝对额。OCF>净利不充分证明高质量：折旧、营运资本释放、保理/供应链融资、分类政策都需检查。

FCF=OCF−购建长期资产支付现金，明确资本开支定义。并购支付现金、融资租赁、资本化研发与利息分类单列，避免重复扣除。不是天然FCFF或FCFE。年内FCF不简单乘年化，主估值用可可靠还原的TTM。负FCF保留金额、原因、CapEx/OCF；按用户约束不输出负FCF Yield，用“不适用：TTM FCF非正”替代。缺TTM可列全年/YTD FCF，不能标签冒充TTM。

现金流桥优先读“将净利润调节为经营现金流”附注：合并净利润+折旧摊销/减值等非现金项−经营资产现金占用+经营负债现金来源+其它已披露调整。仅有余额时制作“简化桥”，分别列−Δ存货−Δ预付−Δ应收+Δ合同负债+Δ应付及已知项；余额变动含并购、汇兑、减值、非现金购置，不自动等于现金流。缺项不能当0。残差=实际OCF−已纳入估算，写未核实残差与待查科目，不能凭量级断言折旧主导或回款无风险。

Δ存货−Δ合同负债仅称“存货—预收款增量差/简化垫资代理”，不是实际自有资金缺口，也不是全部订单覆盖；还需应付、预付、应收、现金和融资数据。

## 4. 营运效率与订单代理

DIO=平均存货/同区间营业成本×区间天数；DSO=平均应收/营收×天数；DPO=平均经营性应付/采购成本×天数，采购额未披露时用营业成本作代理并注明；CCC=DIO+DSO−DPO。使用真实区间天数或明确统一360/365，期间口径一致后可对比年度与YTD，同期季节性仍须说明；不能将年内天数统一用全年天数。季度最好平均季度期初末余额，不能只拿期末余额算出“已披露周转”。票据、合同资产、预付是否纳入全表一致。

存货YoY与营收同区间YoY并列，剪刀差定义固定为营收YoY−存货YoY(pp)。前者是时点存量增速，后者是区间流量增速，仅作线索；并购、价格上涨、季节性、存货净额跌价与备货阶段可能改变信号。结合原材料/在产品/成品、库龄、跌价、预付款、应收及履约节奏，不下“只有一种解释”的结论。

合同负债/存货是“预收款存量比”，按售价口径的负债和成本口径存货不匹配、客户预付款比例不同，不能说覆盖了多少订单或某批存货。增速比=合同负债YoY/存货YoY仅辅助：存货增速≤0、接近0、任一基数低或两者负增长都不宜作订单强弱判据。阈值据历史可靠样本定义，没有依据不设固定1.5倍等参数。B2B赊销模式合同负债低不证明没有订单。

递延收入可作合同负债的经核验类比；RPO含已确认递延收入与尚未开票的履约义务，是合同披露不是资产负债表负债，不能直接替代合同负债参与比值/现金流桥。prepaid expenses不能不核含义就当供应商采购预付。

行业适配：备货型制造盯库存结构与CCC；晶圆/面板等重资产盯产能利用率、ASP、转固、折旧、CapEx/OCF、ROIC；软件平台盯经核验递延收入、RPO、续费与回款；银行/保险不强算制造业存货CCC/EV，列不适用并选资本充足、不良、偿付等法定行业指标。

## 5. 债务、流动性与研发

有息负债由短借、长借、债券、借款一年内到期、租赁等明细独立加总，去重，不是“总负债减应付减合同负债”。经营占款单列，不等于无风险负债。净负债=有息负债−可自由支配现金及等价物，受限现金单列；缺受限明细不能宣称全现金可用于偿债。总负债/OCF优先TTM，OCF≤0不输出负倍数优劣判断。流动比率=流动资产/流动负债；简化速动比率=(流动资产−存货)/流动负债，并说明仍含预付等；严格口径另剔除不可速动资产。现金/短期有息债、利息保障、净债/EBITDA须同口径正分母。

研发费用率=费用化研发/营收；资本化率=当期资本化研发/当期研发总投入，不用开发支出余额代替流量。研发绝对额和人员数量有则逐期，无则明示缺失，不能默认为0。人均指标用披露员工人数口径，年末人数不是平均人数，并购时注明。

## 6. 分市场定价，不混淆市值和倍数

先核实同一发行人和经济权利、股份类别、ADR/ADS换算、总发行股数与各类股份数；不能把两个不同实体当A+H。当地市场股份价值=当地股价×该类发行股份数，保留原币并折RMB；只用流通股数得到的是流通市值，不能叫该类总市值。ADR通常代表已计入本地股份的同一权益，严禁重复计数。

按用户报告约束，不输出各市场加总市值；允许分别列同一总股本的价格等值整体股权价值：E_m=该市场每基础股CNY价格×已发行总普通股股本。ADR每份含k基础股，先把报价/汇率换成每基础股价格。这种“全股本统一按某市场价格”的值是估值参照，不是该类股份市值。

PE_m=E_m/TTM归母；静态PE=E_m/最近年度归母；扣非PE=E_m/真实还原的TTM扣非；PB_m=E_m/归母权益；PS_m=E_m/TTM营收；ForwardPE=E_m/同口径一致预期归母。不能用“该市场股份价值/集团全部利润”算该市场PE，少股本市场会虚假更便宜。利润≤0写不适用。公司公布EPS用加权平均/稀释股本，与当前总股本资本化法可能不一致，列说明；BPS需总同权股份分母。

H/A价差=H每基础股价折CNY/A每基础股价−1；同权条件验证后称“本次收盘与汇率下价格折价”，不是收益套利或下单建议。写价差基准方向，市场流动性、税费、渠道、交易限制有核对资料才补。非同权不直接给哪里更划算。

EV_m=E_m+有息负债+经核实少数股东权益/优先股−可用现金，选简化口径需标明省略。EBITDA使用披露/可调节值，营业利润不直接代EBIT，缺折旧/利息等就不算倍数。

## 7. 历史估值、PEG与宏观锚

每个市场单独历史序列：区间、频率、样本数、当时有效股本、财报实际发布日期PIT可见性、复权/拆股调整、异常剔除规则。只保留有定义的正PE样本并披露亏损期间被排除。经验分位=(低于当前样本数+0.5×等于当前样本数)/N×100，分位线25/50/75使用注明插值法。上市不足五年称“上市以来/可用区间分位”，不能补上市前交易日。今天利润回填历史价格、或前复权价格除未复权EPS会制造假曲线。

PEG=PE_TTM/G，G输入为百分数数值。默认正利润同口径三年CAGR，另给至少一种换起止/扣非/可靠前瞻对照。对每种G独立判适用，不因某一种负G就让所有PEG失效；跨亏损、并表不可分、低基数和一次性主导时仅列局限性/不宜使用。Forward PEG需明确分子是ForwardPE而非混用TTM。

盈利收益率EY=TTM归母/E_m，利润非正不据此宣称便宜；正TTM FCF Yield=TTM FCF/E_m。两者不是债券票息或预期股票回报。EY−国债收益率称“盈利收益率—国债利差/简化估值参照”，不叫真正ERP；ERP是预期股票总回报减匹配无风险利率，不能用静态盈利收益率直接代替。RMB估值主对中国同币种国债，美债补充海外融资/需求环境，原币折RMB不能消除汇率风险。

10Y−3M美债=(两收益率百分数之差)×100bps，同日同种收益率。单日正利差只说明非倒挂，不能证明正在陡峭化；走陡须历史斜率变化，需分熊陡/牛陡，不能断言不是衰退预警。只有匹配数据时解释宏观传导到公司已披露业务敞口。
